## Project Overview
The goal of this group coursework is to develop a **Student Record Management System (SRMS)** for a university that demonstrates practical use of advanced Java programming concepts.

The system allows management of student records with features such as:  
- Adding, updating, and removing student records to and from a file  
- Loading and saving records to files  
- Generating detailed reports (e.g., by GPA, department, or year)  
- Processing multiple tasks simultaneously using features such as auto-saving and report generation  

## Features
- **Student Management:** Add, update, delete, and view student records  
- **File Handling:** Load and save student data to files  
- **Reports:** Generate reports based on GPA, department, or year  
- **Multithreading:** Support for simultaneous tasks like auto-saving and report generation  
- **User Interface:** User-friendly interface for easy interaction  

## Technologies Used
- Java (Object-Oriented Programming)  
- File Handling in Java  
- Multithreading  
- UML for system design  
- Git & GitHub for version control
